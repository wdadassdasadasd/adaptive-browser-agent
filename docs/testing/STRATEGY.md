# 按风险选择的测试与 Agent 评测策略

现行目标、AC 与门槛由根规格／契约和 [冻结协议](../evaluation/CURRENT_EVAL_PROTOCOL.json)决定；本页说明如何选择检查，不替换 [V1 测试矩阵](V1_TEST_MATRIX.md)或历史结果。

| 层 | 对象与典型证据 | 触发条件 |
| --- | --- | --- |
| L0 | Ruff、格式、类型、锁与配置校验；记录命令／退出码 | 改相应代码、依赖或配置时；文档变更至少检查链接与结构。 |
| L1 | 纯逻辑、状态、解析和失败边界单元测试 | 改业务决策、事实准入、预算或状态归约时。 |
| L2 | API／Schema／事件／数据库约束及兼容测试 | 改公开接口、持久结构或消息语义时。 |
| L3 | 真实隔离 PostgreSQL 上的 API、Worker、租约及事件集成 | 改事务、队列、取消、恢复或权限路径时。 |
| L4 | Vue → API → 任务及历史的端到端交互 | 改用户流程或跨端状态时。 |
| L5 | 崩溃、失租、数据库失联、未知结果及资源释放注入 | 改长任务／外部调用／恢复边界时。 |
| L6 | 官方来源、完整任务、轨迹、费用及人工核源的真实 Agent 评测 | 只有按现行协议和逐次授权执行；离线与 Mock 不计真实成功。 |

任务包先记录基线，再选足以覆盖改动风险的层；不机械要求文档修改运行全套 E2E。CI 现有 Python 3.12／3.13 离线检查、PostgreSQL 16 集成和前端检查见 [workflow](../../.github/workflows/ci.yml)；本地实际命令以当前环境和任务包记录为准。CI 绿灯不证明 Windows／WSL 冷启动或真实来源准确。

## 技术验证、独立审查与业务验收

技术检查依据可观察契约和实际风险选择；Bugfix 尽量保留能证明原缺陷的回归，避免仅复述实现。独立 Review 按 [G5 规则](../engineering/WORKFLOW.md)执行，普通行为变化也需要独立上下文；测试通过不替代审查，专项审查不替代受影响的测试。修复发现后重跑受影响检查，行为变化再独立复审，最终证据对应最终内容。

AI 为 G6 准备可运行入口、关键差异、正常及失败路径的验收步骤、预期结果、实际证据和未知项；用户亲验关键业务流程，分别记录技术验证与业务验收。实现完成、检查通过、人工验收和产品 Go 是不同结论；失败或缺授权时保留结果，不自行改验收标准。

改变决策行为的工程规则／Skill／模板除链接、元数据与配置检查外，还需独立审查和现实任务场景验证：需求不清、重要设计、普通修复、模块依赖推进、验收失败、完整 Diff 与修复复审、无 Git 授权、新项目缺全局环境等。静态 validator 只证明其已覆盖的结构约束；桌面／CLI／IDE 的发现和触发分别实测，未实测标待验证，离线场景不算真实 Agent 质量评测。

DECISION-001 的补充复核在**同一冻结报告快照**上逐项检查硬条件、事实支持、未知与冲突、条件变化后的理由；保存报告 SHA-256、fact ID、复核者和时间。它与正式九题分母独立，额外真实任务需要新预算及单独授权。发现断言或门槛失败时保留原样本并给出 No-Go，不通过删样本、降低阈值或将未知费用写零使其通过。

### 实施检查与准备检查分开

T07-01需逐写入口验证父任务及event/fact/call/cost/report附属guard；只证明旧claim拒绝不够。冻结旧Store/model/DTO最小闭包，测试有效token/lease下的旧方法也不能写decision数据；missing/NULL/错误protocol、OLD/NEW归属、kind转换、SET LOCAL池清理、恢复扫描、共同容量/FIFO及唯一终态均覆盖。附属写拒绝应使同事务budget回滚，不把它升级为F1资金保护。具体命令/预期及授权见[任务包](../features/DECISION-001/tasks.md)。

T07-02只交付context/phase/资源接口；session/revision/report/task/event/active原子终态归T08。T12-02的对象绑定及新代次旧登录/grant失效，须等待真账户和T08 schema集成；占位ID或假供应商通过不能算资金保护全验收。线索撤销/admission两种提交次序在T10接入后补真实隔离Pg集成，不用进程锁模拟替代。

本轮实际适用检查：现有validator及声明ledger、六文件链接、所有新JSON解析、来源文件/hash/locator、候选引用、9/8/12唯一slots与顺序、三轮评分及金标隔离、资金算术/授权false/正式协议hash、范围外原字节/HEAD/暂存/gitlink、完整task-owned差异。检查脚本和输出追加在原审计目录，不改业务校验器或测试源码。独立技术与安全审查读取固定的六份全文、全部新材料及task增量/HEAD差异；最终结果补记变动也绑定新指纹并复核。
