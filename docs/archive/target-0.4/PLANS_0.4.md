**状态：0.4 APPROVED 目标计划；2026-10-18，尚未实施。** 与 [SPEC.md](SPEC.md)配套；用户明确批准 0.4 并切换设计权威，[0.3 设计索引](docs/design/00_DESIGN_INDEX.md)保留历史。本轮已获授权的范围仅是研究、审计、规格、仓库配置与离线验证。原来的 **57 小时 / 四周**仅估算单用户方案；团队目标因账户隔离、同机 Worker、HTTPS、异机备份与可核源建议重估为约 **120 小时 / 九周**（每周约 13–14 小时），不包含本轮准备工时、硬件升级或付费模型费用，亦不构成业务代码、付费运行或实际部署授权。估算在容量实测后需再校准。

## 里程碑与停线

1. **准备完成**：0.4 目标、研究报告、现状审计、三个 Skill、离线校验和 CI 可审阅；用户已确认设计权威，业务仍需逐项授权。
2. **定位通过**：调用级原因有证据，缺口可观测；否则先补观测，不凭推测重构。
3. **团队边界通过**：本地账户、归属、对象级授权和迁移回滚有证据；API/Worker 分进程的认领、取消、SSE 与唯一终态通过故障回归。
4. **离线、容量与恢复通过**：受影响契约、失败分支、资源生命周期及 Windows 主机约 20 会话/8 待处理任务经过验证；实际运行槽由资源证据确定。内网 IP HTTPS、客户端 CA 信任、每日异机加密备份与月度恢复通过；不以 Token 降低代替目标完成。
5. **真实闭环诊断**：B01–B03 各一次真实链路，失败保留并形成下一故障任务；无费用授权时停在此门前。
6. **正式 Go/No-Go**：冻结代码后 B01–B03 各 3 次且各 ≥2 次完整成功，公开 G01–G03 各 1 次且合计 ≥2 次完整成功；每次完整成功全字段、可核源建议和逐条实质结论，且跨账户隔离保持。所有十二次与失败原件保留。任何门槛不足或核源不完整，结论为 **No-Go**。
