# 历史资料与路径映射

归档文件保留迁移前的字节和 SHA-256；[R0 路径映射](R0_PATH_MAP.json)逐项记录旧路径、新路径和当前文件哈希。`kind: historical` 的哈希在迁移前后相同；`kind: current_task` 的任务包调整了相对链接，另有 `old_sha256` 保存移动前哈希。旧文档中的相对链接依照其原始路径解释，再由映射找到新文件；这不改变历史正文，也不赋予旧规格现行效力。
