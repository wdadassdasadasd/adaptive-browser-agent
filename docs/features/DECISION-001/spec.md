## 价值与失败判定

Agent侧仅本产品＋本人手工搜索/核源/重写；Control侧普通AI＋一次独立DR/题＋手工核验。两侧相同预注册日常引擎清单，不设手工query条数上限但计全部主动时间。禁止用外部AI/Control输出代修Agent；人脑迁移无法消除，实际记录。共同质量覆盖全部硬条件与推荐/排除关键主张、主体/版本、反证和可行动验证计划，不简化为若干事实数。最终合格人稿用于价值比较，原始程序质量、安全和授权结果不被改写。

本人与AI工时、条件费用、正式揭题与延期规则由计划和唯一协议定义。真实报告、核源、演示、本人读码/解释/亲改、技术检查及业务接受分别记录；没有发生的实践不填写已掌握。无资格、unknown、预算/容量不足、未处理决定性反证或工具失败都必须有可见停止原因。
