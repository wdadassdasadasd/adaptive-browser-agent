# DECISION-001 独立决策复核记录模板

状态：未执行。每次复核复制一份，绑定**同一份不可变报告快照**；本模板不改变 `docs/evaluation/CURRENT_EVAL_PROTOCOL.json` 的九题、十五次与人工官方核源门槛。

| 字段 | 记录 |
| --- | --- |
| 任务 ID／运行 ID／题目 ID | 待填 |
| 代码 Commit SHA、模型与工具配置 | 待填；无 Commit 时记录源码快照哈希 |
| 报告文件路径与 SHA-256 | 待填；无报告记 `null` |
| 原始事实、事件及调用轨迹路径与 SHA-256 | 待填 |
| 用户用途、硬条件、偏好、候选快照 | 待填；不得从页面推断用户条件 |
| 复核者与 UTC 时间 | 待填 |

逐候选 × 逐条件记录：候选 ID、条件类型与原文、报告判断、支持／反证 fact ID、逐条官方 URL 与最小片段、主体与抓取时间、人工核源结果（通过／失败／未知）、冲突或遗漏、复核结论与理由。对推荐另记录：适用条件、所有关键 fact ID、硬条件是否遵守、未知是否披露、改变一个条件后的结论是否合理、是否仍需团队实测。

失败、未知和无法打开的来源必须保留。机器 `satisfied` 不等于人工核源通过；无报告、哈希不符、关键事实错主体／缺片段、费用未知或正式协议未通过时写明 No-Go。离线复核与正式评测分开统计，不增加或删除正式尝试，也不得用本模板推断新的真实成功率。
