# 0.5 目标契约（未实施）

本文细化 [SPEC.md 0.5](../../SPEC.md) 的安全和数据边界。当前 V1 实际行为仍由 [V1 契约](V1_CONTRACTS.md)及源码决定；0.4 [历史规格](../../SPEC_0.4.md)不作为新任务目标。字段/HTTP 状态码/DDL 在明确授权的 G3 任务中冻结，不凭本文声称已上线。

## API 与身份

现有六路研究路径保持：`POST /api/research`、`GET /api/research`、`GET /api/research/{task_id}`、`GET /api/research/{task_id}/trace`、`GET /api/research/{task_id}/events`、`POST /api/research/{task_id}/cancel`。保留提交、列表、详情、trace、SSE、取消的核心语义；新增 `POST /api/auth/login`、`POST /api/auth/logout`、`GET /api/auth/me` 和管理员开通、停用、重置本地账户接口。可加首次改密路径，但不得开放自助注册。所有研究路径先认证，再按 `owner_id` 对列表/详情/trace/SSE/取消过滤；他人任务统一不可见，不以错误差异泄漏 ID。管理员不默认阅读成员研究内容。

服务端会话令牌随机产生、只存哈希；Cookie 使用 Secure、HttpOnly、合适的 SameSite 与过期时间。密码用自适应哈希，登录限速，有副作用的 Cookie 请求防 CSRF，停用账户立即撤销会话。账号、令牌、重置凭据、CSRF 秘密绝不进入 Agent Prompt、trace 或报告。参考 [OWASP 会话](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)及[密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。

## 持久数据和事件

PostgreSQL 应用表至少表达账户/会话、owner-scoped 任务、执行尝试/租约、取消请求、准入事实与来源、社区补充、建议/报告、单调编号用户事件和旧数据导入映射。LangGraph 检查点在单独边界内，仅用于节点执行恢复；不能替代应用表的终态、事实和审计。研究事件沿用 V1 六类语义，字段可兼容扩展；事件和业务状态在同一事务提交，SSE 从已提交事件按 ID 补读。通知只是唤醒。每任务至多一有效租约及一终态；过期租约、取消与重试须原子裁决，正式容量目标 2 running + 8 queued。

关键事实含 subject、claim、source URL、核验状态与 fact ID，只有官方来源核实才可进入关键事实。社区补充另存、标注 `community_supplement`、其来源和核验限制，不单独支持关键结论。建议为分析层，记录文本、适用条件、supporting fact IDs、官方 URL、取舍/未知项。旧报告可无新字段；新任务 `completed/full` 必须有足够事实、条件化建议和一致的终态。报告不能把分析写成官方原文。

## 故障与旧数据

Worker 在同一任务崩溃后最多自动恢复一次：使用检查点和应用已提交事实，换新浏览器会话，重新观察与规划；结果不明的工具动作不得原样重放。第二次故障终结 `partial` 或 `failed`，留下原因和已接纳事实。取消为持久请求，唯一终态不可逆；资源在成功、失败、取消时关闭。

V1 SQLite 保持只读和原样留存。导入以旧记录稳定 ID 做幂等映射、可校验原件哈希；只初始管理员可查询旧任务，不将其自动归给成员。导入不能重写 r12 原始记录、评分或把旧任务计为新正式评测。

## 部署边界

同机 HTTPS 代理只向局域网暴露受认证入口；API、Worker、PostgreSQL 和管理面不直接对 LAN 开放。浏览器外联禁止私网/环回/链路本地等地址，含 DNS 解析、重定向、点击、弹窗和子资源；需在实际 Chromium 路径证明，未证实则部署 No-Go。每日一致性备份在异机加密留存 30 天，每月恢复演练。容器优先，原生回退须达到同等访问与恢复要求。
