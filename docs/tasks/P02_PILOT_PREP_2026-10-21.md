- `evaluation.pilot_runner` 默认命令无动作；显式 `--execute` 还要求单独授权引用、有效价表、同一快照绑定的预算、当前三题计划、原项目总账及哈希、loopback API 和独立输出目录。它按 owner 范围幂等键串行提交 B01–B03，逐次等待/超时取消/证据捕获/总账追加；对模糊 HTTP 响应从 PostgreSQL 恢复，不重复创建任务。任何非完成终态、未知费用、证据不稳、未入账任务或数据库费用变化即停止后续提交。三次捕获只标“待人工复核”，不生成正式合格结论。

证据导出中途若只留下部分文件，执行器会保留原件并拒绝推进；操作者需核对数据库与 provider 账单，再另起可追溯的恢复/新 cohort，不删除或覆盖已发生尝试。这里的幂等恢复保障的是任务提交和完整账本快照的重入，不把不完整捕获自动判为成功。
