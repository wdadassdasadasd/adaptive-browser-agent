## 兼容与验收检查

1. 现有仅 `goal` 请求及六路 API 返回保持兼容；新增上下文不改变六态、取消、SSE、owner 和费用语义。
2. 决策上下文只来自用户输入；公开网页不得写入硬条件、系统规则或会话身份。已给定候选与检索发现的候选有明确来源区分。
3. 正常、关键缺证、错主体、来源冲突、候选均不满足、取消、预算不足及失租均有独立用例和可追事实。
4. 正式九题继续按 current-3 原协议逐结论人工官方核源；补充复核应保留报告 SHA-256、复核者和未验证项。
